# Figures

This directory contains five selected plots generated by the R analysis scripts and shown in the [main project README](../README.md#results-and-visualisations).

| Figure | Description |
| --- | --- |
| [heart_kaplan_meier_smoking.png](heart_kaplan_meier_smoking.png) | Kaplan–Meier curves by smoking group, using the coursework's non-standard event convention |
| [heart_schoenfeld_diagnostics.png](heart_schoenfeld_diagnostics.png) | Schoenfeld diagnostics for BP and Anaemia |
| [lung_cox_predicted_survival.png](lung_cox_predicted_survival.png) | Model-estimated lung cancer survival curves |
| [pension_life_tables.png](pension_life_tables.png) | Life tables under constant force and UDD assumptions |
| [pension_log_mortality_rates.png](pension_log_mortality_rates.png) | Log crude central mortality rates by age and sex |

Original heart-patient and pension-scheme CSV files are not distributed. Figures are statistical summaries or fitted model outputs from coursework data. The heart analysis models the assignment-defined **transition event**, not death-event survival; see the [methodological notes](../docs/methodological_notes.md).

The plots can be regenerated locally according to the [README instructions](../README.md#how-to-reproduce) with authorised input files.
