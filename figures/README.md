# Figures

These plots are generated by the R scripts after the necessary data files have been placed locally:

- Heart: Kaplan–Meier curves by smoking status, Schoenfeld diagnostics.
- Lung: model-estimated survival curves from the selected Cox model.
- Pension scheme: log crude mortality rate curves and four life-table profiles.

Figures are not included in this initial public-ready archive because the supplied original data have not been cleared for redistribution. Review output charts before committing them to a public GitHub repository.
